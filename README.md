# Quiz

Hello, this project is made for generating and participating into tests and Quizes

## Project structure
### Authorization
You can Authenticate with your email and pass, or with your Google account
### Backend
In Quiz-project there is the Supabase project used as backend and also as authorization server for email and pass auth
### Hosted
The Quiz project is hosted here: https://quiz-2b5f.onrender.com
It uses the Render service for hosting

## Development server

To start a local development server, run:

```bash
  ng serve-dev
```
